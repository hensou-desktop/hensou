# Interview archive

files-interview.md preserves the planning record from Mountainous at commit a905fd62. It is historical context, not the current build instructions.

The final app stack is cxx-qt and Android is dropped. Hensou contains the toolkit and desktop essentials. Pyxamp and Forgerie stay in independent repositories. Current ownership is ../decisions/0004-product-ownership.md; current product scope is ../design/files.md. Earlier proposals to import Pyxamp or extract its service clients into Hensou are superseded.

Temporary paths in the interview refer to experiments on Zao. They are not required by the scaffold and may no longer exist. API and toolkit observations must be checked again before implementation. Prototype measurements are not promises about finished apps.
