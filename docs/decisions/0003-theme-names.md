# The Windows-inspired theme is called Memphis

The owner chose **Memphis** as the name of the Windows-inspired theme on 2026-10-30. Earlier, Memphis and Tempo were only suggestions. No legal or trademark clearance has been done for the name.

On 2026-11-05 the owner made Memphis the identifier as well: the persisted theme names are `platinum` and `memphis`, and code, file names, tests and documentation say Memphis everywhere. No Windows version name appears anywhere in the repository. This replaces the earlier rule that kept a separate legacy identifier.

There is deliberately no alias for the previous saved value. A saved choice from before the rename is not recognised and falls back to Platinum, as any unknown name does; the user picks Memphis again once. The cost is that one-time reset on any host that had Memphis selected at the switch.

Memphis's light appearance is labelled **Standard**, chosen by the owner on 2026-11-05 in place of Microsoft's colour-scheme name "Windows Standard". Its dark appearance stays "Dark grey". The saved modes stay `light` and `dark`.

The Mac-inspired theme keeps the name Platinum. The scaffold includes no upstream theme art, fonts or trademarks as project branding.
